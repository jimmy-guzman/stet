stet is two panes in one window: the repository tree and the file viewer. The viewer is always open. The tree docks to an edge, resizes, and closes, so you can shape the window around whatever you are doing.

The project search pane (`ctrl-f`) is not a third pane. It replaces what the viewer shows, inside the viewer, and keeps its query and results when you close it.

## Move between panes

`tab` switches focus between the tree and the viewer. Clicking a pane focuses it, and the wheel scrolls whichever pane the pointer is over.

The panes have no box around them: a thin divider runs between the tree and the viewer, and the header and status bars are drawn as rules with their text inset. The focused pane is the one showing its cursor highlight: the tree lights its cursor row, the viewer lifts its caret line and brightens its file name, and the search view lights its selected result, each only while focused, so taking focus never moves anything.

| Control  | Action                                   |
| -------- | ---------------------------------------- |
| `tab`    | switch focus between the tree and viewer |
| `ctrl-b` | show or hide the tree                    |
| `esc`    | close the search view; it never quits    |

Focus never rests on a closed pane: hiding the tree while you are in it hands focus to the viewer. Quitting is `q`, which asks first.

## Resize the tree

`[` and `]` resize the tree and `\` returns it to its default size. The tree is the one pane with a size of its own; the viewer is whatever it leaves, so these keys act on the tree from the viewer too.

The tree resizes along the edge it is docked to, two columns on the left or right and one row on the top or bottom, which are about the same distance on screen because a terminal cell is taller than it is wide.

The tree keeps a separate size per axis. Moving it from a side to the top does not turn its width into a height, and moving it back restores the width you set.

<Callout>
  Shrinking the tree past its minimum (24 columns, or 5 rows) closes it, the way
  an IDE pane collapses rather than clamping. `]` reopens it at the size you
  left it.
</Callout>

## Dock the tree to an edge

`d` moves the tree to the next edge, clockwise through left, top, right, and bottom, so four presses return it home. The tree starts on the left, and the viewer takes the rest of the window.

## Zoom one pane

`m` fills the window with the focused pane and pressing it again restores the layout. Zoom follows focus, so `tab` while zoomed changes which pane fills the window.

The geometry keys (`[`, `]`, `\`, and `d`) do nothing while zoomed, since their result would sit hidden behind the zoomed pane. Showing or hiding the tree leaves zoom.

## Keep a layout

Press `ctrl-s` to save the current arrangement, along with your other session settings, to your config. The `sidebar` section also takes these directly; see the [configuration reference](/docs/reference/configuration#features) for every key and its default.

Within the viewer, files stay open as tabs with their own history. Those are covered in [reading files & diffs](/docs/guides/reading-files-and-diffs#tabs-and-history).
