stet has two panes in one window: the repository tree and the file viewer. The viewer is always open. You can dock the tree to an edge, resize it, and close it. Use these controls to shape the window around your task.

The project search pane (`ctrl-f`) is not a third pane. It replaces the content of the viewer, inside the viewer. When you close it, it keeps its query and results.

## Move between panes

`tab` moves focus between the tree and the viewer. A click on a pane focuses it. The mouse wheel scrolls the pane under the pointer.

The panes have no box around them. A thin divider separates the tree and the viewer. The header and the status bar show as horizontal lines with their text inside.

The focused pane is the pane that shows its cursor highlight. The tree highlights its cursor row. The viewer brightens its caret line (the line of the current position) and its file name. The search view highlights its selected result. Each pane shows its highlight only while it has focus, so a change of focus does not move anything.

| Control  | Action                                   |
| -------- | ---------------------------------------- |
| `tab`    | switch focus between the tree and viewer |
| `ctrl-b` | show or hide the tree                    |
| `esc`    | close the search view, never quit        |

Focus never stays on a closed pane. If you hide the tree while it has focus, focus moves to the viewer. To quit, press `q`. stet asks you to confirm first.

## Resize and dock the tree

`[` makes the tree smaller, `]` makes it larger, and `\` sets it back to its default size. The tree is the only pane with its own size. The viewer takes the space that the tree leaves. These keys change the tree even when the viewer has focus.

The tree resizes along the edge that it docks to. On the left or right edge, each step is two columns. On the top or bottom edge, each step is one row. The two steps are about the same distance on screen, because a terminal cell is taller than it is wide.

The tree keeps a different size for each axis. If you move it from a side to the top, its width does not become a height. When you move it back, it gets the width that you set.

<Callout>
  If you make the tree smaller than its minimum (24 columns, or 5 rows), it
  closes. An IDE pane collapses the same way, instead of stopping at a minimum.
  Press `]` to open it again at the size that you left it.
</Callout>

`d` moves the tree to the next edge. The order is clockwise: left, top, right, and bottom. Four presses bring the tree back to its start. The tree starts on the left, and the viewer takes the rest of the window.

## Zoom one pane

`m` makes the focused pane fill the window. Press `m` again to restore the layout. Zoom follows focus. If you press `tab` while zoomed, the other pane fills the window.

While zoomed, the layout keys (`[`, `]`, `\`, and `d`) do nothing, because their result stays hidden behind the zoomed pane. If you show or hide the tree, zoom stops.

## Keep a layout

Press `ctrl-s` to save the current layout and your other session settings to your configuration. You can also set the layout directly in the `sidebar` section. The [configuration reference](/docs/reference/configuration#features) lists each key and its default.
