## Switch scope

A scope is the pair of points that the diff compares. Press `s` to choose a scope. The scopes are in two groups. The changes group has uncommitted, staged, and unstaged changes. The history group has everything since stet started, and the last commit. The picker also lists recent commits (`commits →`), so you can view any of them as its own diff.

![The scope picker grouping the diff scopes under changes and history](/screenshots/scope-picker.png)

To start in a scope from the command line, run `stet --staged` or `stet --unstaged`. To compare against a branch, tag, or commit, run `stet <ref>` with its Git ref.

## Switch worktrees

A Git worktree is an extra checkout in its own folder. Press `w` to change to a different worktree without leaving stet. The list puts the most recently touched worktree first, so the worktree that an agent works in is at the top. Each row shows its age (`now`, `5m`, `3h`).

Type to filter by branch or by the folder name of the worktree. Press `↑`/`↓` to move and `⏎` to switch. The filter ignores the folder path that all worktrees share. That text is the same in each row, so it always matches all rows at once.

After the switch, the tree, the diffs, polling, and checks use the selected worktree. Below the list, stet shows the full path of the highlighted worktree.

![The worktree picker, worktrees ranked by how recently each was touched, each with its age, and the highlighted one's full path below the list](/screenshots/worktree-picker.png)

Touched means any work by an agent or by Git in that worktree. Examples are an uncommitted edit, a commit, a checkout, a rebase, or the creation of the worktree. A commit counts too, so a worktree does not drop down the list when an agent finishes its work.

The color of each age shows how recently the worktree was touched. It fades toward the background over five minutes without activity. A changed file stays marked for 30 seconds. A worktree uses a longer window, because an agent can pause for minutes and still be at work. The age shows recency, not live presence. A recent age means that work landed there recently. It does not mean that something runs there now.
