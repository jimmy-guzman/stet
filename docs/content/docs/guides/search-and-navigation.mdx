## Open a file

The tree lists folders before files. Names use natural, case-insensitive order, so `file2` comes before `file10`. A chain of nested folders with one child each shows on one row.

When you move onto a file, stet previews it. When you open a folder, its children show or hide, and the current preview stays. The [navigation keybindings](/docs/reference/keybindings#navigation) list the folder controls and the keys for the first and last visible items.

To open any file without the tree, press `ctrl-p`. It opens a fuzzy search over the whole repository, for tracked and untracked files. A fuzzy search matches the letters that you type in order, with gaps allowed.

![The go-to-file overlay fuzzy-matching paths across the repo](/screenshots/go-to-file.png)

## Find in the viewer

Press `/` to search in the open file. `n` and `N` move to the next and previous match. A counter shows your position, and `esc` clears the search.

![Find-in-viewer highlighting matches in the open file with a match counter](/screenshots/find.png)

## Search file contents

Press `ctrl-f` to open the project search pane. The results are grouped by file, with highlighted lines around each match. A glob is a path pattern with wildcards, such as `*.ts`.

| Control      | Action                                              |
| ------------ | --------------------------------------------------- |
| `ctrl-r`     | toggle regular-expression matching                  |
| `ctrl-x`     | toggle case sensitivity                             |
| filter field | include or exclude globs, such as `src/ !*.test.ts` |
| `ctrl-g`     | search changed files or the whole tree              |
| `ctrl-o`     | choose a diff scope without leaving the pane        |

Open a match to go to its file. stet keeps the query and the results, so `ctrl-f` shows the same search again.

![Project content search listing matches for a term across several files](/screenshots/search.png)

## Follow recent activity

While the agent works, stet marks the files that changed recently. Press `.` to go to the most recently changed file. The mark beside a file fades as the change ages, so the brightest mark is the newest.
