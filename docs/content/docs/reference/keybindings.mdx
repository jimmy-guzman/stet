## Custom keybindings

You can rebind each key above in the `keybindings` section of your [configuration](/docs/reference/configuration). Map a rebind id from the tables to a combo, to a list of combos, or to `false` to remove the binding.

```jsonc title="~/.config/stet/config.jsonc"
{
  "keybindings": {
    "toggle-sidebar": "ctrl+e", // one combo
    "cursor-down": ["j", "↓"], // several
    "toggle-wrap": false, // unbind
  },
}
```

A combo is optional `ctrl` or `shift` modifiers, joined by `+` or `-`, then a key. The key is one of these:

- A letter
- A symbol, such as `?` or `[`
- An arrow, such as `↑` or `up`
- An F-key
- One of `tab`, `enter`, `return`, `esc`, `space`, `backspace`, `delete`, `insert`, `home`, `end`, `pageup`, or `pagedown`

A single uppercase letter means shift, so `"G"` is the same as `"shift+g"`. Modifiers must match exactly, so a binding of `"s"` never fires on `ctrl+s`. The one exception is shift on a symbol key, which stet ignores.

The tables show the primary combo of each action. Some movement actions also keep an arrow as a second default: `↑` / `↓` beside `j` / `k`, and `←` / `→` beside `h` / `l`.

If an id is unknown, or a combo does not parse, stet keeps the default. If you bind one combo to two actions, stet registers both. The internal dispatch order of stet decides which one fires, not the order of these tables. Do not rely on that order. Set the action that you do not want to `false`.

At startup, stet shows only the first configuration problem that it finds, so a different problem can hide a keybinding problem. `?` and `--help` always show the bindings that are in effect.

Keys in overlays (pickers, menus, the quit confirmation, and the search pane) and `ctrl+c` are fixed. After you press `enter` in a find, `n` and `N` move between its matches until `esc` clears it.

## Mouse

You can also use the mouse:

- Click a file to open it, a folder to expand or collapse it, or a diff line to move the caret there.
- Double-click a file in the tree, or a tab in the tab strip, to pin it as a tab.
- Click items in the overlays and the search pane.
- Hover over a theme in the switcher to preview it live.
- Click a pane to focus it. The wheel scrolls the pane under the pointer.
- Right-click a tree row or a viewer line to open a context menu of the actions that apply there. `Shift+F10` opens the same menu on the focused pane.

![The viewer's context menu listing its copy and open actions](/screenshots/context-menu.png)

The menu shows only the actions that apply where you open it, so it can be shorter. For example, a folder in the tree offers only Copy path. The menu shows no disabled items.

Drag across diff lines to select a range. If you hold the pointer at the top or bottom edge, the viewer scrolls and the selection continues. If the terminal forwards `Shift+mouse`, a shift-click extends the range. Some terminals keep that gesture for their own text selection. Drag and `Shift+↑` / `Shift+↓` work in all terminals.
